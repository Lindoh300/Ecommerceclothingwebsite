# 4Nguru The Brand handover

The code is on the `musa-ui-changes` branch. Supabase is deployed. The Vercel Preview, the merge to `main` and the removal of the sample data remain.

| File | What it is for | Who needs it |
|---|---|---|
| `OWNER_HANDOVER.md` | Where things stand, the deploy order, and what to check before merging | Owner, first |
| `TEST_PLAN.md` | Step-by-step checks to run on the Vercel Preview and live site | Owner, second |
| `SUPABASE_SETUP.md` | How the Supabase project is set up and configured | Owner and developer |
| `REMAINING_WORK.md` | Work still to do, and open decisions | Owner and developer |
| `CHANGELOG.md` | Release notes of user-visible changes | Owner |
| `AGENTS.md` | Developer guide to the code, structure and rules | Developer |
| `demo-data/README.md` | How to remove the sample products, events and gallery items | Owner, before real trading |
| `demo-data/remove.sql` | The SQL that removes the sample data, run by the steps in the README | Owner (through the README) |
| `demo-data/ATTRIBUTION.md` | Photo credits and licences for the sample photos | Owner |

`AGENTS.md` is an unedited developer guide. Its links to `docs/` point to local planning files that are not in this folder.
